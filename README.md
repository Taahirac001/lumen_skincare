# Lumen Skincare storefront

Dawn-based theme for lumen-skincare.myshopify.com plus the shop's product discount function.

| Path | What it is |
|---|---|
| `assets/` | Theme CSS |
| `config/` | Theme settings schema and data |
| `layout/` | Theme layout |
| `sections/` | Header and footer sections |
| `snippets/` | Price snippet |
| `templates/` | JSON templates (index, product) |
| `extensions/product-discount/` | Product discount function |
